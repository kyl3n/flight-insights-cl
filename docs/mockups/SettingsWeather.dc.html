What the requests contain

Checked by tests on every build
  • Every number in a request is a tile grid point or a schedule time; nothing comes from a flight.
  • Requests run on the same schedule whether or not anyone flew.
  • New tiles are backfilled over the same fixed window, after a random delay, so no request points at a flight date.
